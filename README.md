# trading-bot-samples

Sample trading bots for the ANDX exchanges. Each sample is self-contained — pick one, copy it, and build
from there.

| Folder | Exchange | Docs |
|---|---|---|
| `andx-usa` | ANDX USA | https://docs.andx.one |
| `andx-global` | ANDX Global | https://docs.andxus.io |

The two exchanges use different APIs and separate credentials; a key issued by one will not work on the
other. See the README inside each folder for its samples and setup.
